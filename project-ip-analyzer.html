View Code on GitHub Live Demo

Overview

The Suspicious IP Analyzer is a Python-based tool that automates the analysis of SolarWinds SEM logs. It enriches IP addresses using VirusTotal and AbuseIPDB APIs, providing actionable threat intelligence for SOC analysts.

Key Features

  • Parses SolarWinds SEM log files for suspicious IPs
  • Enriches IPs with VirusTotal and AbuseIPDB data
  • Generates detailed threat reports in PDF/CSV
  • Identifies brute force patterns and malicious activity
  • Reduces manual threat analysis time by 70%

Tech Stack

Python VirusTotal API AbuseIPDB API Pandas ReportLab SolarWinds SEM

Impact

This tool was deployed in a SOC environment, reducing alert triage time by 40% and enabling analysts to quickly identify and block malicious IPs. Over 500+ suspicious IPs were analyzed in the first month.
